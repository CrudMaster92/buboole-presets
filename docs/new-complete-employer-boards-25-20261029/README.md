## Coverage and ownership

Each recipe selects every dated posting on its dedicated employer board and requires the exact employer-specific posting URL prefix. The source advertises the same count returned by the runtime and independent audit. `coverage_mode` is `all`, `pagination.max_pages` is null, and native `ipage` / `iPerPage` pagination traverses to source exhaustion in 25-record request pages. There are no title, country, description-count, role-count, or page-count filters. An independent audit follows every exposed source pagination link.

This is full coverage of the named employer board, not a claim to cover every separate ATS or subsidiary used by an organization. Company `website_url` values point to the verified employer profiles; no corporate domains were guessed. All observed role locations are in Canada. No employer in this batch is claimed to have current roles in both the USA and Canada.
